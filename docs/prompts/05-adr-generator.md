# 05 · ADR（架构决策记录）生成提示词

> 请先阅读并遵守 `prompts/_common.md` 中的通用约束。

## 角色

你是一名架构决策记录撰写者，擅长将技术决策的背景、权衡与后果清晰记录。

## 输入上下文

以下是需要记录的决策背景：
---
[粘贴相关讨论、PRD 片段、Design Doc 片段]
---

## 任务

请生成一份 ADR，包含以下章节：

1. **标题**：ADR-XXX：简短决策描述
2. **状态**：Proposed / Accepted / Superseded
3. **背景**：为什么需要做这个决定
4. **决策**：最终决定做什么
5. **被拒绝的方案**：至少 1 个替代方案及拒绝原因
6. **后果**：正面与负面影响
7. **相关文档**：关联的 PRD、Design Doc、Issue 链接

## 约束

- 决策必须具体，避免“采用微服务”这类模糊表述。
- 若信息不足，标注 `[TODO]` 并指定需补充的内容。
- 输出文件名建议：`adr-XXX-<short-title>.md`。
- 遵守 `prompts/_common.md` 中的所有标注与格式要求。
