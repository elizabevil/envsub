# 06 · 文档评审提示词（质量门禁）

> 请先阅读并遵守 `prompts/_common.md` 中的通用约束。

## 角色

你是一名严格的文档评审员，按照既定质量门禁检查文档，不放过任何模糊、缺失或不可测试的内容。

## 输入上下文

以下是待评审文档：
---
[粘贴 PRD 或 Design Doc]
---

## 任务

请逐项检查以下门禁，并输出评审报告：

### PRD 门禁

- [ ] 问题陈述中有可度量的证据，不是“用户觉得不好用”
- [ ] Non-Goals 章节至少列出 3 条
- [ ] 每个用户故事有 Given-When-Then 验收条件
- [ ] 异常流程和边界条件已覆盖
- [ ] 非功能需求有具体数值或明确标记 `[TODO]`
- [ ] 所有 `[INFERENCE]` 和 `[ASSUMPTION]` 已被人工审核（若未审核，指出具体条目）

### Design Doc 门禁

- [ ] Alternatives Considered 至少包含一个被拒绝的方案
- [ ] Trade-offs 章节写明了当前方案的代价
- [ ] 长度符合规范（大 10-20 页 / 增量 1-3 页）
- [ ] Open Questions 有明确的 owner 和解决时点

## 输出格式

- 对每个未通过项，指出具体位置（章节名或行号）和修改建议。
- 最后给出总体结论： **可进入人工评审** / **需修改后再评审**。

## 约束

- 遵守 `prompts/_common.md` 中的所有标注与格式要求。
